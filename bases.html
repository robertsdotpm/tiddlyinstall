Base installers

A base installer is a finished, tested installer with one open slot, the x. Its code never changes. What it installs, and the name and icon of the installed app, come from its settings.

Prototype: sample data.

install_python_x

Installs the Python package x from PyPI or a GitHub repo into its own copy of the newest Python the computer supports.
