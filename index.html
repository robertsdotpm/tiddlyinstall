Real installers for Windows, Linux and macOS, straight from a GitHub repo.

No freezing and no bundlers that break. We install your project's real runtime and dependencies into fixed, shared locations, clone your project, and install it against them. The result is an ordinary installer built with NSIS on Windows and the Qt Installer Framework on Linux and macOS.

How it works

1. Point at a repo

Give us a GitHub repository and a branch, tag or commit. We clone the actual source code.

2. Pin the dependencies

Choose the runtime and its version. Each dependency is installed once, in a fixed per-version folder that other installers can share.

3. Build for every platform

We package the result as a Windows .exe (NSIS) and a Linux .run and macOS .dmg (Qt Installer Framework).

Dependencies live in fixed locations

Every dependency is installed to SYS_DRIVE / DEP / DEP_VERSION. Two apps that need the same Python never install it twice, and nothing is stuffed into a frozen bundle.

Windows   C:\python\3.12.4\
          C:\git\2.46.0\
Linux     /python/3.12.4/
macOS     /python/3.12.4/

Base installers are reusable

Every installer is built from a base installer. For example, install_python_x.exe installs the Python package x. To make a new installer you change the target, embed your own metadata and swap in your own icon. You don't rebuild the whole pipeline.

install_python_requests.exe   -> installs the "requests" package
install_python_black.exe      -> installs the "black" package
install_node_prettier.exe     -> installs the "prettier" package
