Edit  Installer

Edit an installer

Change what an unsigned installer installs, its name and its icon. Editing happens in your browser. Your file is never uploaded.

This is the self-contained editor: one file with the Windows, Linux and macOS base installers inside. It works offline, from a USB stick or any web host.

01  Open

Open an installer

Made on this site as an unsigned installer.

Or drop it here. .exe for Windows, .run for Linux, .zip for macOS.
Or start a new one from a base installer
Base installers come from the build server, or from inside this page when it is the self-contained editor.

Signed installers can't be edited without losing their signature. If you open one, it will be saved unsigned and Windows and macOS will warn people who run it. To retarget an installer signed by TiddlyInstall, rename it instead.

03  Contents

Packed files

Files carried inside the installer. The installer uses a packed copy of any download whose SHA-256 matches, instead of downloading it.

A pack is addressed by hash, so a member's name says nothing about it. What names each one — including which is the 32-bit runtime and which the 64-bit, when an offline installer carries both — is the Install plan above: its file lines give each download's SHA-256 and its architecture, per [target] block (docs/format.md section 4). An installer packing more than one architecture of a runtime must carry its plan rather than fetch it, or nothing can tell them apart.

    macOS apps can't be signed in the browser: macOS only opens a downloaded app

    ditto -x -k install.zip . && cd Install.app/Contents/Resources
codesign -f -o runtime --timestamp -s "Developer ID Application: …" tiverify-arm64 tiverify-x86_64
cd ../../.. && codesign -f -o runtime --timestamp -s "Developer ID Application: …" Install.app
ditto -c -k --keepParent Install.app upload.zip
xcrun notarytool submit upload.zip --keychain-profile <profile> --wait
xcrun stapler staple Install.app && ditto -c -k --keepParent Install.app install-signed.zip
