    Who signed what

    A signature on the installer program says who wrote that program and that it has not been altered. A signature on the plan says the plan came from a resolver unchanged. Neither is a statement about the software being installed.

    Checked against the build server

    No build server is set, so only what is inside the file could be read. A server can also say whether these settings are ones it published, whether the plan is still the one it would give you, and whether it has been revoked since this file was built.
