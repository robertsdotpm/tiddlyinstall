    Who signed what

    A signature on the installer says who wrote the installer and that it has not been altered since. A signature on the install recipe says the recipe came from our build server unchanged. Neither says anything about the software being installed.

    Checked against the build server

    No build server is set, so only what is inside the file could be read. A server can also say whether these settings are ones it published, whether it would still hand out the same downloads today, and whether this installer has been withdrawn since it was built.
