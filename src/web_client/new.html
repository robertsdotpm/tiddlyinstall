Signing and the installer file

SigningUnsigned

A signature here goes on the installer program - the one we wrote, the same in every installer built here - and never on the software it installs. It says the program that asks for someone's trust at install time is the one it claims to be, unaltered; it is not a word about your app, which whoever signs cannot have checked.
