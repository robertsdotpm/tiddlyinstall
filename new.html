Offline copies

Packs everything the installer would download, for computers without internet. Tick Also make offline installers above to set this up.

Offline copies also carry everything the normal installers would download: the runtime, packages and source, and any of your files set to download when installing. The normal installers are still made too.

Install scripts

Optional. Scripts run after the user has seen what the installer will do and clicked Install. People can view them on that screen. If a script exits with an error, the install stops and shows its output.

Available: %IB_APP_DIR% %IB_RUNTIME_DIR% %IB_APP_NAME%. Runs with the installer's permissions (usually administrator).
Available: $IB_APP_DIR $IB_RUNTIME_DIR $IB_APP_NAME. Plain POSIX sh, which every Linux and macOS system has; bash isn't guaranteed. Runs with the installer's permissions (root for installs for all users).
UninstallUninstaller registered, asks about your app's data The app's data

Files the app saved in its data folder while it was used.

Before-removal script

Runs before anything is removed, e.g. to stop a background service. People can view it before uninstalling. If it fails, its output is shown and the removal carries on.

Same variables as install scripts: IB_APP_DIR, IB_RUNTIME_DIR, IB_APP_NAME.

Uninstalling deletes the app's own folders. Nothing shared with other apps is touched.
