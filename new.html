What are base installers?
Up to 255 characters including the extension. Letters, numbers, _ - . only. Installers signed by Installer Builder get a hash of their settings added to the end, e.g. install_python_requests_tjfq5rqw….exe.
One key = value per line. Stored with the installer's settings. Package, versions and app ID are added automatically.

Install locations

Each dependency goes to SYS_DRIVE / DEP / DEP_VERSION, for example C:\python\3.13.1\ on Windows and /python/3.13.1/ on Linux and macOS. The version is whichever one the installer picked.
