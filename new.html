Install locations

Every app gets its own copy of every dependency. Nothing is shared between apps, so one app can't break another, and uninstalling deletes the app's folders.

Windows  C:\ib\k3m9q2x7v4p8\     app
         C:\ib\tjfq5rqwnnrx\     its Python
Linux    /opt/ib/tjfq5rqwnnrx/
macOS    /Library/Application Support/ib/tjfq5rqwnnrx/
Folder names are short hashes, to keep paths short. Each folder has a manifest saying what it contains.

An offline installer carries the files the normal one would download. It's made in your browser: files go from the download sites straight into the installer, and are never uploaded to us. The normal installers are still made too.

What you'll get
WindowsOne .exe. The files sit inside its signature block, so the signature stays valid.
LinuxOne .run.
macOSA .zip with the app and a folder of files next to it. macOS apps can't carry extra files without breaking their signature. Users keep the two together.

Every included file is checked against a checksum in the installer's settings, so a changed file is refused. Files from download sites that don't let browsers fetch from them come through our download relay instead.
