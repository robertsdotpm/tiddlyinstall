## Data quality notes to review

- **Python 3.8 Windows OS support** in `python/limitations.json` says Vista and later. The operator's tested builds use 3.7.0 for Vista, and 3.8 may not support Vista officially. Check.
- **python.org's API** records the checksum and size of the *decompressed* tarball for old `.tgz` source files; handled by `python/fix_tgz_checksums.py` and `applies_to: decompressed`.
- **Checksum coverage is weak** for older LLVM (pre-2025 GitHub assets and releases.llvm.org), GCC source, MSVC redistributables, most archived PHP Windows builds, and R on macOS/Linux. Those downloads are verified by size only.
- **Limitation confidence** is mostly low for C/C++ toolchains and R 1.x/2.x; see each `limitations.json` `confidence` field.
