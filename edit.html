Edit an installer

Change what an unsigned installer installs, its name and its icon. Editing happens in your browser. Your file is never uploaded.

This is the self-contained editor: one file with the Windows, Linux and macOS base installers inside. It works offline, from a USB stick or any web host.

Open an installer

Or drop it here. .exe for Windows, .run for Linux, .zip for macOS, made on this site as an unsigned installer.
Or start a new one from a base installer
Base installers come from the build server, or from inside this page when it is the self-contained editor.

Signed installers can't be edited without losing their signature. If you open one, it will be saved unsigned and Windows and macOS will warn people who run it. To retarget an installer signed by Installer Builder, rename it instead.

    Retarget a signed installer by renaming it

    Installers signed by Installer Builder read their file name. Renaming keeps the signature.

    install_python_requests.exe   installs requests
install_python_black.exe      installs black

    Names are limited to 255 characters. Letters, numbers, _ - . only.
